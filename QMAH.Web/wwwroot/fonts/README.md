# 後台字體

後台使用本地 WOFF2，登入與管理頁不需要等待第三方字體服務，也能在沒有外網的展示環境維持相同的字體配置。

- `Plus Jakarta Sans`：英數、數值與控制介面，字形清楚且比單一通用無襯線字體更有辨識度。
- `Noto Sans TC`：繁體中文正文、表單與資料表。
- `Source Serif 4`：英文展示標題。
- `Noto Serif TC`：中文展示標題。

目前檔案是依專案介面與展示資料做子集化的 WOFF2。新增少見字元時，CSS 會回到系統字體，不會顯示成空白；若要讓新增字元也使用專案字體，請重新依現有文字內容產生子集檔案。

字體均來自 Google Fonts，依 SIL Open Font License 1.1 發布；對應授權文字放在本目錄的 `OFL-*.txt`。
