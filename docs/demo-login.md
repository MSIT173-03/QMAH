# 展示帳號快速填入

## 第三方登入

所有環境採相同規則：首次同 Email 的 Google／Logto 身分會綁定到既有會員，沿用原會員資料。一般帳密會員仍須先完成信箱驗證，停權與鎖定限制保留。新增的綁定會寫入資料庫。

此規則尚未檢查各第三方的信箱可信性，不代表已完成安全綁定機制。登入頁的帳密快速填入仍僅限 development 建置，與第三方綁定規則無關。

## 帳密填入

Angular 登入頁在 development 建置時提供可展開的「展示帳號快速填入」區塊。
選擇帳號後按「填入帳號密碼」，再按原本的「登入」按鈕。填入時會取消「記住我」。

本機帳密存放於 `QMAH.Client/.demo/demo-accounts.json`，此目錄已被 Git 忽略。
檔案內容為陣列，每筆包含 `displayName`、`email`、`password`、`role` 字串。
組員需要自行取得這份本機設定；Git 不會同步它。設定不存在時不顯示快速填入區塊。

只有 Angular development 設定會複製該檔到 `/demo/demo-accounts.json`。
正式 production 建置不包含此資產，也不載入展示帳號。
變更 angular.json 後需重新啟動前端開發伺服器。

此功能只填入既有表單，不會新增會員、驗證信箱、調整角色或繞過後端登入檢查。
role 僅為設定資訊，真正權限仍由後端決定。
前台 Angular 登入頁提供此功能，MVC 後台登入頁尚未加入。

開發伺服器的使用者可以讀到這份帳密檔，因此只使用專用展示帳號，展示後停用或更換密碼。
