# 明信片模板規則

商品詳情直接重用 `app-collectible-card`，傳入 `[image]`、`[name]`、`[type]`、`[dimensions]`、`[description]`。禁止每件商品複製元件或產生專屬動畫。

- 自動判斷只讀圖片載入後的自然尺寸：`naturalWidth >= naturalHeight` 使用橫式明信片，否則使用直式明信片；不以名稱、類型或尺寸文字猜方向，也不旋轉來源圖片。
- 卡片採 A6 148 × 105 mm：橫式為 `148 / 105`，直式為 `105 / 148`；若未來輸出送印檔，四周各加 3 mm bleed，成為 154 × 111 mm。
- 橫式正面採圖片主區加右側紙面文字欄；郵務面左側約 45–48% 放文物資訊，右側約 52–55% 保留給郵票、六碼郵遞區號、地址及收件人。
- 直式正面維持直立圖片與右側文字欄；郵務面改成郵票／地址在上、文物資訊在底部，郵票黏貼區位於左上。正反面方向與長寬必須一致。
- 正面名稱與類型印在獨立紙面欄，避免文字受作品明暗影響；背面完整顯示尺寸與既有說明、正式 Logo、郵票預留區、六碼郵遞區號框及地址線。
- 說明不做字數或行數裁切，會依標點提供優先換行點；若來源含完全無標點的超長片段，才允許瀏覽器保底斷行以免超出紙面。
- 橫式與直式共用紙面寬 30 mm 的 Logo（高度依原檔比例）、32 × 24 mm 郵票視覺框、30 × 6.5 mm 郵遞區號框；依 A6 方向換算，不受資訊欄寬度影響。區號使用暖灰 0.2 mm 細框，六格尺寸不縮小。直式郵票、區號、地址線及資訊帶共用 5 mm 外側邊界。
- 字級及間距統一使用紙面單位：名稱 4 mm、類型及尺寸 2.6 mm、說明 2.5 mm、地址行距 8 mm。螢幕只縮放整張卡，橫直模板不再各自設定像素字級下限；這些是設計尺寸，不代表螢幕顯示的實際毫米。
- 書畫、繪畫、書法、畫冊與冊頁類型保留完整構圖；其他類型以 cover 等比裁切。方向仍只由原圖自然長寬決定。
- 郵票預留區只顯示小型文字框，不加入齒孔、面額或類似郵資符誌；框尺寸是本專題的視覺規格，不宣稱是法定框尺寸。地址面維持白色、平整、可書寫，不配置 QR Code 或大面積深色圖案。
- 實體紙材規格為白色 180–250 g/m²；建議約 220 g/m² 非塗佈紙。這是印務條件，不由前端 CSS 假裝保證。
- 共用一張約 4 KB 的紙紋；列表繼續使用縮圖，只有詳情使用此元件。
- 本版為省資源採 CSS 3D，沒有 Three.js、WebGL、持續 requestAnimationFrame 或商品貼圖生成工作。印刷感為紙紋與墨色合成，並非物理材質渲染。
- 翻面軸只設定 transform 與 preserve-3d；不要在軸上加 opacity、filter、overflow:hidden 或固定紙色底板，避免壓平與穿牆。
- 原生 button 支援 Enter／空白鍵，降低動態偏好會停用轉場。修改後跑 npm run build，並檢視正面、背面及翻轉中段。

2026-09-19：已通過 Angular production build；橫式與直式正反面均在同一元件集中切換，不需為單件商品另寫版型。

規格依據：[中華郵政明信片規格說明](https://www.post.gov.tw/post/internet/Q_localpost/index.jsp?ID=1462781067740)、[USPS Address Side of Cards](https://pe.usps.com/Archive/NHTML/DMMArchive20230122/201.htm)。本元件仍是商品視覺化模板，實際送印前需由印務端依寄送地再次校稿。
