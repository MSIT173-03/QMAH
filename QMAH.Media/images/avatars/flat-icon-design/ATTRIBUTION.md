# 展示頭貼素材來源

本資料夾的預設展示頭貼取自 [FLAT ICON DESIGN](http://flat-icon-design.com/)，作者為 TopeconHeroes。

## 使用範圍

依該網站的素材利用條件，素材可免費嵌入網站、應用程式與展示資料，使用時不需要另外報告或標示著作權。素材本身及改作後的素材不得另行整理成素材包販售或再發布，也不得使用 FLAT ICON DESIGN 的素材建立另一個素材下載網站。

QMAH 只把素材作為會員的預設展示頭貼，沒有提供原始素材下載或素材搜尋功能。檔案已下載並隨專案保存，執行時不會連回素材網站。
